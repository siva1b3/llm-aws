# Laws

## Law 1 — File protection

Create empty placeholders for missing required files and folders without user approval. Use a valid JSON placeholder for JSON files. Never edit existing Markdown files inside the protected folder.

## Law 2 — Roles and expected outcomes

Before execution, every action item must define each participating party's role and expected outcome in JSON. These definitions must be specific to that action and must never be missing, empty, or undefined. Each expected outcome must be clear enough to verify whether it was achieved. Roles and expected outcomes may differ between actions. This law applies to every individual action item, including each item within a larger plan.
