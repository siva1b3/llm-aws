# Project rules

This folder contains the stable project contract and agreed technical choices.

Read [project-guide.md](project-guide.md) first. Read [technical-reference.md](technical-reference.md) when technical setup or implementation becomes relevant.

Active work and blockers belong in [project status](../project-status/README.md). Observations and findings belong in [project evidence](../project-evidence/README.md).

Update these documents when an agreement or governing decision changes. Then reconcile affected status and evidence.

The rewrite follows [project-context-guide.md](../project-context-guide.md) and its clarity guidance from [asd-ste100.md](../asd-ste100.md).
Use short sentences, direct instructions, consistent terms, and one topic per paragraph. Preserve conditions, uncertainty, and technical meaning.
These practices do not establish verified ASD-STE100 compliance.
